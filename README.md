## WordSpace

WordSpace is a full-stack blogging platform built entirely by me using Laravel. It allows users to create and interact with content through posts, comments, and likes, while providing separate user and administrator functionality.

### Features

* User registration and authentication
* User profiles and personal dashboards
* Create, edit, and manage posts
* Like and comment functionality
* Published and draft posts
* Role-based authorization
* Dedicated admin panel
* Admin management of users, posts, and comments
* Admins can also use the normal user dashboard and manage their own posts
* RESTful API for application data and interactions

### Technologies

* **Backend:** Laravel, PHP
* **Frontend:** Blade, HTML, CSS, JavaScript
* **Database:** MySQL
* **Authentication:** Laravel Breeze
* **API:** RESTful API
